## Preserve data behavior

Use `{ranges:["'10.31.2026'!A104"]}` to read and `{data:[{range:"'10.31.2026'!A20:B20",values:[[12,34567]]}]}` to write. Objects, not serialized JSON strings. RAW is default; explicit USER_ENTERED preserves existing intentional percent/formula parsing. Empty strings clear; null/undefined/nonfinite values are rejected. On source failure: clear ONLY the failed source's current owned ranges, leave that status not-done, set its existing alert cells, retry. Do not fall back to Zapier.

Do not migrate cell locations based on the old registry: it names A50–A59 while the exported live prompts confirm A100/A101/A102 (Occupancy), A104/A105/A106 (ShowMojo), A108/A109/A110 (Sales), A112/A113/A114 (CFA), and A116/A117/A118 (CF Leads), respectively status/alert/alert. Preserve all existing current status/alert cell references and source definitions.

Sales alone calls `sheets_create_day_tab({date:'YYYY-MM-DD'})`. It duplicates the latest earlier daily tab, sets A1 to the M.D.YYYY title text, clears the existing Oct 12 stale range list in the SAME atomic batch, and verifies far-right placement. Retries never clear an existing tab. After all Sales work, call again with `housekeeping_only:true` to hide date tabs older than the trailing seven days. Others are writer-only and stop on a missing tab.
